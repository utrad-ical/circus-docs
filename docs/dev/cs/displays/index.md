---
title: Built-in Displays Overview
---

This section explains the built-in displays currently available on CIRCUS CS.

| Name                                                        | Function | Purpose                                                             |
| ----------------------------------------------------------- | :------: | ------------------------------------------------------------------- |
| [Choice](/docs/dev/cs/displays/choice)                      |    🎤    | Shows toggle buttons to obtain user feedback                        |
| [Dump](/docs/dev/cs/displays/dump)                          |    📺    | Dumps raw results data for debugging                                |
| [LesionCandidates](/docs/dev/cs/displays/lesion-candidates) |  📺&🎤   | Shows series with lesion candidate marks and collects user feedback |
| [Locator](/docs/dev/cs/displays/locator)                    |    🎤    | Lets user click locations of a volume                               |
| [Numeric](/docs/dev/cs/displays/numeric)                    |    🎤    | Lets user input a numeric value                                     |
| [Text](/docs/dev/cs/displays/text)                          |    🎤    | Lets user input a string                                            |
| [VolumeOverlay](/docs/dev/cs/displays/volume-overlay)       |    📺    | Shows series with colored volume overlay                            |
| [Gallery](/docs/dev/cs/displays/gallery)                    |    📺    | Shows result images with label                                      |
| [Tags](/docs/dev/cs/displays/tags)                          |    🎤    | Let users attach tags for feedback                                  |

📺: Presentation, 🎤: Feedback collection

<Note>

More built-in displays will come soon. If you have a feature request, please file it on our GitHub repository.

</Note>
